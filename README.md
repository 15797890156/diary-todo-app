# 🌸 日记待办应用

可爱简约的个人生活管理工具

## 功能特性

- 📅 **日历** - 月/周/日视图，收支概览
- ✅ **待办清单** - 待办管理，完成追踪
- 📝 **日记** - 图文日记，心情记录
- ⏰ **时间表格** - 作息/专注/事项三栏表格
- 📊 **四象限** - 紧急/重要任务矩阵
- 💰 **收支记账** - 21个分类，月度汇总
- 🏆 **完成板块** - 所有完成事项汇总
- 📦 **产品追踪** - 消耗品/目标/习惯进度

## 技术栈

- Flutter 3.x
- Riverpod 状态管理
- SharedPreferences 本地存储

## 部署

本项目支持自动部署到 GitHub Pages：

1. Fork 或上传此仓库到 GitHub
2. 进入 Settings → Pages
3. Source 选择 GitHub Actions
4. 等待构建完成
5. 访问 `https://你的用户名.github.io/仓库名/`
